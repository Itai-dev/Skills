# Itai's Skill Library

All of Itai Agami's Claude skills in one place, so they don't get lost and can be browsed, installed and (later) sold.

- **Browse:** open [`site/index.html`](site/index.html) in a browser. It is one self-contained file with every skill's full instructions.
- **Install in Claude Code:** add this repo as a plugin marketplace, then install a shelf:

  ```
  /plugin marketplace add Itai-dev/Skills
  /plugin install itai-sales@itai-skills
  ```

  Shelves: `itai-design`, `itai-marketing`, `itai-sales`, `itai-business`, `itai-ai`, `itai-projects`.
- **Use in claude.ai:** zip a folder from `skills/` and upload it under Settings → Capabilities → Skills.

## Layout

```
skills/<name>/SKILL.md     one folder per skill (plus any files it uses)
catalog.json               shelf, source and licence for every skill
scripts/build.mjs          validates the catalog and regenerates the files below
site/template.html         the library page (edit this one)
site/index.html            generated page with the data inlined
.claude-plugin/            generated marketplace manifest
```

## Adding a skill

1. Put the folder in `skills/<name>/`. The `name:` in its `SKILL.md` must match the folder name.
2. Add a line for it to `catalog.json` (shelf + source). For third-party skills, add the source and its licence.
3. Run `node scripts/build.mjs`. It fails if a skill is missing from the catalog or the names don't match.
